# FANOVA Web App

**Status: PLANNED.** This directory is reserved for the creator/fan experience.

The first UI must support only:
1. Creator publishes an original story with explicit permission rules.
2. Fan submits a contribution linked to that story/version.
3. Creator approves or rejects.
4. UI displays attribution, decision, and honest chain/evidence status.

Keep mocked/local/mainnet states visibly distinct. Do not add marketplace, DAO, broad social features, or AI generation to the MVP.
